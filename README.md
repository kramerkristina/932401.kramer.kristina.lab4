# Лабораторная работа №5

**Тема:** Любитель кино и сериалов (Вариант 6)  
**Выполнила:** Крамер Кристина

## Описание проекта
В данной лабораторной работе реализована интерактивная работа с DOM деревом и сохранение данных в `localStorage`. 

## Реализованный функционал:
* **Поиск элементов:** Использованы методы `getElementById`, `querySelector`, `querySelectorAll` для привязки логики к HTML.
* **Манипуляции с DOM:** Добавлена возможность динамически создавать новые строки `<tr>` в таблице фильмов и полностью очищать `<tbody>` без перезагрузки страницы.
* **Переключение темы:** Реализована смена темной и светлой темы через добавление/удаление класса `light-theme` у тега `body`.
* **Видимость блоков:** Реализовано скрытие и показ контейнера с таблицей по клику на кнопку.
* **Сохранение состояния (localStorage):** Данные таблицы (добавленные фильмы) и выбранная тема оформления сохраняются в браузере и автоматически восстанавливаются при обновлении страницы.
* **Обработка ошибок:** Добавлены проверки на существование элементов в DOM перед назначением обработчиков событий и валидация пустых полей ввода.
